# HVACo · Petersburg HVAC Repair Guide

An independent, source-linked guide to HVAC repair companies serving Petersburg, VA 23805 and the Tri-Cities area.

- **17 companies** compared on ratings, review volume, BBB complaint records, pricing and red flags
- **Priority shortlist** with call order and click-to-call
- **Searchable directory** with an evidence dossier for each company
- **Repair price benchmarks** and advertised local prices
- **Hiring checklist** and phone questions

Research snapshot: November 16, 2026. Ratings are source-specific and not blended. No paid placements. Verify licensing on [Virginia DPOR](https://dporweb.dpor.virginia.gov/LicenseLookup/Search) before hiring.

## Files

- `index.html`: the site
- `data/companies.js`: company research data
- `research/dashboard.html`: full interactive research dashboard

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000. It's a static site, so GitHub Pages works as-is (Settings → Pages → deploy from `main`, root).
